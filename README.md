# ⚽ Fixture Mundial 2026

Interactive World Cup 2026 fixture app built with **JavaScript**. Browse groups, matches, and results in real time.

## ✨ Features

- Full 2026 World Cup fixture and groups
- Match schedule and results tracker
- Responsive design
- Pure JavaScript — no frameworks

## 🛠️ Tech Stack

- **JavaScript (Vanilla)**
- **HTML5 · CSS3**

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/Abalito04/Fixture-Mundial-2026.git
cd Fixture-Mundial-2026

# Open in browser
open index.html
```

Or just open `index.html` directly in your browser — no build step needed.
